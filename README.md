## Now building: [Epoch](https://github.com/CosmiCodeArcher/epoch)

<a href="https://github.com/CosmiCodeArcher/epoch"><img src="https://raw.githubusercontent.com/CosmiCodeArcher/epoch/main/docs/theme-morph.gif" alt="Epoch's clock morphing through six Omarchy themes" width="720"></a>

A clock for Omarchy with alarms, timers, a stopwatch and world clocks. Timers are processes you can chain with `&&`, alarms only stop when you type the label backwards, and the whole window morphs to the new palette when you switch themes.
